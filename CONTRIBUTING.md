# Contributing

Contributions should improve a real operational task while keeping this skill small and independent.

- Explain the user task and the observable problem before proposing a rule.
- Preserve the explicit-use boundary and existing-project precedence.
- Prefer adaptable guidance over universal pixel mandates.
- Keep every example synthetic. Do not submit customer names, private domains, production identifiers, credentials, or screenshots of private systems.
- The demo uses browser-native HTML, CSS, and JavaScript. Keep it runnable without a build step, external requests, or added runtime packages.
- For demo changes, inspect desktop and narrow layouts; exercise search, filters, keyboard focus, dialogs, state previews, and density switching. Include relevant screenshots and describe what was actually checked.
- Keep English and Chinese usage documentation consistent when behavior or installation changes.

Please report reproducible problems through this repository's Issues. A useful report includes the client or browser, invocation or reproduction steps, expected behavior, actual behavior, and sanitized screenshots when applicable.
