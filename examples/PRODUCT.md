# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

People evaluating the compact-admin-ui Agent Skill, including developers and interface designers.

## Product Purpose

Demonstrate a compact business-interface style through fictional support, order, and record-detail examples.

## Capabilities and Constraints

- Public, local-first examples shipped with the skill.
- Every organization, person, record, and value is synthetic.
- No production connections, external fonts, runtime dependencies, or data collection.
- Preserve task clarity, readable information, and useful interaction states.
- Illustrate spacing decisions with the same data in spacious and compact modes.

## Brand Commitments

The user selected the name compact-admin-ui and the compact, restrained style expressed in SKILL.md.

## Evidence on Hand

Authored examples, runnable source, and captured screenshots. They demonstrate these examples and are not benchmark evidence for all agents or projects.
